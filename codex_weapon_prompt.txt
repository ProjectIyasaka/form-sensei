## 目的
武道AI解析SaaS（form-sensei）に武器先端の軌跡追跡機能を追加する。
MediaPipeの手首・肘ランドマークから武器先端位置を推定し、動画フレーム全体に軌跡を描画する。

## 実装内容

### 1. src/lib/weapon-tracking.ts（新規作成）

LandmarkPoint型はsrc/lib/storage.tsからインポートする。

エクスポートする型：
- WeaponTipPoint = { x: number; y: number; time: number }
- WeaponConfig = { lengthMultiplier: number; dominantHand: 'right' | 'left' | 'auto'; trailColor: string; trailWidth: number; trailFade: boolean; }

エクスポートする関数：

1. estimateWeaponTip(landmarks: LandmarkPoint[], config: WeaponConfig, currentTime: number): { tip: WeaponTipPoint | null; hand: 'right' | 'left' | 'both' }
   - landmarks[16]=右手首, landmarks[14]=右肘, landmarks[15]=左手首, landmarks[13]=左肘
   - dominantHand='auto'のときy座標が小さい（画面上方）手を選択
   - 右手首と左手首の距離 < 0.15 なら両手持ちとみなし、両手中点を起点にlandmarks[11](左肩)とlandmarks[12](右肩)の中点から手首中点方向に延長
   - 先端 = 手首 + (手首 - 肘) * lengthMultiplier
   - tip.time = currentTime

2. drawWeaponTrail(ctx: CanvasRenderingContext2D, points: WeaponTipPoint[], currentTime: number, config: WeaponConfig, canvasWidth: number, canvasHeight: number, fadeDuration?: number): void
   - 古い点から新しい点へ線を引く
   - trailFade=trueのとき、fadeDuration(デフォルト3.0)秒前の点は透明度0、現在に近いほど不透明（線形補間）
   - 座標は0~1正規化 → canvasWidth/canvasHeightでpxに変換

3. drawWeaponTip(ctx: CanvasRenderingContext2D, tip: { x: number; y: number } | null, config: WeaponConfig, canvasWidth: number, canvasHeight: number): void
   - 先端位置に半径6pxの塗りつぶし円を描く
   - trailColorで塗りつぶし、白でアウトライン

### 2. src/components/VideoAnalyzer.tsx（修正）

以下の変更を加える：

A) importに追加（../lib/weapon-trackingから）：
   estimateWeaponTip, drawWeaponTrail, drawWeaponTip, WeaponTipPoint, WeaponConfig

B) コンポーネント内にuseRef/useStateを追加：
   const weaponTipsRef = useRef<WeaponTipPoint[]>([]);
   const weaponConfigRef = useRef<WeaponConfig>({ lengthMultiplier: 2.0, dominantHand: 'auto', trailColor: '#f59e0b', trailWidth: 3, trailFade: true });
   const [weaponConfig, setWeaponConfig] = useState<WeaponConfig>({ lengthMultiplier: 2.0, dominantHand: 'auto', trailColor: '#f59e0b', trailWidth: 3, trailFade: true });
   ※weaponConfigが変更されたらweaponConfigRef.currentも更新するuseEffectを追加

C) フレーム解析ループ内でPoseLandmarkerで骨格取得した後、modeRef.current === 'weapon'のとき：
   storedLandmarksがnullでなければ estimateWeaponTip(storedLandmarks, weaponConfigRef.current, video.currentTime) を呼び、tipがあればweaponTipsRef.current.push(tip)

D) canvas描画時（骨格描画の後）にmodeRef.current === 'weapon'のとき：
   drawWeaponTrail(ctx, weaponTipsRef.current, video.currentTime, weaponConfigRef.current, canvas.width, canvas.height)
   最新tipがあれば drawWeaponTip(ctx, 最新tip, weaponConfigRef.current, canvas.width, canvas.height)

E) 動画リセット時にweaponTipsRef.current = []をクリア

F) weapon modeのUI（'武器先端の認識は今後...'のpタグ部分）を以下に差し替え：
   - 武器長さスライダー: label='武器長（前腕の倍率）', input type=range min=1.0 max=3.0 step=0.5, 現在値をテキストで表示
   - 利き手: 3択ボタン（auto=自動, right=右手, left=左手）
   - 軌跡色: 3択ボタン（#f59e0b=金色, #22d3ee=シアン, #f87171=赤）
   これらのUI操作でsetWeaponConfigを更新する
