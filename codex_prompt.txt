=== ファイル1: src/components/PoseAnalyzer.tsx ===

React コンポーネント（client:only で使用、SSR不要）。

機能:
1. 画像ファイルのアップロード（input type=file, accept=image/*）
2. FileReader で dataURL に変換し HTMLImageElement に読み込む
3. @mediapipe/tasks-vision の PoseLandmarker を初期化
   - wasmFilePath: https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@latest/wasm
   - modelAssetPath: https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_full/float16/latest/pose_landmarker_full.task
   - runningMode: IMAGE
4. 画像上で detectForImage() を実行
5. Canvas を画像と同サイズで重ね、PoseLandmarkerResult を描画
   - DrawingUtils で骨格ライン + ランドマーク点を描く（緑系カラー）
6. 8箇所の関節角度を計算して UI に表示
   - 左肘・右肘・左膝・右膝（各2箇所）＋左肩・右肩
   - angle = arccos(dot(vecA, vecB) / (|vecA| * |vecB|)) で計算（度数法）
7. ローディング状態（モデル読み込み中 / 解析中）をスピナーで表示
8. Tailwind CSS でスタイリング（ダーク系: bg-gray-900, text-white）
